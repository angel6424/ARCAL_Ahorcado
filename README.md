# Ahorcado ARCAL

Página web estática e interactiva para una actividad educativa sobre ARCAL.

- 7 rondas por partida, seleccionadas al azar desde un banco de palabras.
- 7 errores máximos: cabeza, torso, brazos, piernas y línea final en el cuello.
- Pista opcional mediante botón.
- Estadísticas de la partida y pantalla final.

Autor: Angel Gómez.
Instituto Superior de Profesorado N°3 "Eduardo Lafferriere".
